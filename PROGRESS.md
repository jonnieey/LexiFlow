## New: bare '/' zip entry false-positive in the path-traversal guard (user-reported) — DONE
User report: adding a job in the TUI with a real zip always failed with "No audio/video files found in the job directory"; the CLI log showed the actual cause: `Zip member escapes target directory: /`.
- [x] root cause: `(job_dir / member).resolve()` in the b83515a/36d6ab8 guard hits a pathlib gotcha — `job_dir / "/"` discards `job_dir` entirely (absolute-path override) and resolves to the filesystem root, so a harmless bare root-directory entry (common in zips from many tools) got misidentified as an escape attempt, aborting extraction entirely
- [x] fixed both copies (`lexiflow.base.Transcriptor.mv_extract_job_file` and the tui.py `AddJobScreen` duplicate) — skip members that are exactly `""` or `"/"` before the join/resolve check; real traversal attempts (`../evil.txt`, absolute paths with actual content) are unaffected — commit `12fd534`
